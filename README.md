# Seesaw Algebra (working title)

A browser game that makes the ideas underneath beginner algebra feel obvious
before any symbols are involved. A middle schooler moves objects on a seesaw
while a tutor sits beside them; the math notation appears underneath as a
subtitle.

- Product requirements: [docs/superpowers/specs/2026-10-22-game-algebra-farm-prd.md](docs/superpowers/specs/2026-10-22-game-algebra-farm-prd.md)
- Throwaway prototype (stages 1 and 2): open `spike/index.html` in a browser.
  No build step, no install.

The spike exists to answer one question: does the seesaw feel intuitive to a
real kid? Its code is disposable; what we learn from it feeds the real build.
